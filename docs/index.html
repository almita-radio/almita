ALMITA

Antenna Listening Mostly to Interference, Tentatively Astronomy

ALMITA is an amateur 21 cm neutral hydrogen (HI) radio telescope built in Chile. It combines a Raspberry Pi 5, RTL-SDR receivers, a 1420 MHz science chain, INDI/OnStep mount control, HDF5 acquisition, RFI monitoring and an offline-first observing workflow.

Source code on GitHub Project README

What the project does

Observe
Plans sky mosaics, controls the equatorial mount and records raw I/Q plus metadata in HDF5.
Align
Provides conservative, evidence-driven pointing alignment without arbitrary mount synchronization.
Calibrate
Characterizes the receiver operationally and relatively, including headroom, bandpass behavior and repeatability.
RFI reference
Uses an independent auxiliary SDR chain to monitor the local RF environment around the science observations.
Reduce
Transforms captured data into traceable reduced spectra with masks, calibration metadata, averaging, uncertainty and quality information.
Science
Planned downstream stage for maps, velocity products and higher-level scientific interpretation from reduced spectra.

Instrument workflow

OBSERVE → REDUCE → SCIENCE ↑ CALIBRATE ALIGN supports pointing integrity. RFI_REF supports contamination assessment.

Radio astronomy focus

The principal observing target is the 1420.40575177 MHz neutral-hydrogen line. ALMITA is designed to preserve raw observations, attach pointing and environmental metadata, generate live spectrum and waterfall quicklooks, and support reproducible offline processing.

Current HI measurements are treated as relative / instrumental. Absolute calibration in kelvin is a development goal; the project does not claim an absolute calibration that has not been physically established.

Hardware and software

The project uses a Raspberry Pi 5, RTL-SDR Blog receivers, a 1420 MHz RF chain, an equatorial mount controlled through INDI + OnStep, temperature sensors, Python, NumPy, Astropy, h5py/HDF5, Matplotlib, rtl_tcp and systemd.

Why ALMITA exists

ALMITA explores how far accessible hardware can be pushed toward careful, auditable amateur radio astronomy. The design favors raw-data preservation, explicit uncertainty, conservative calibration claims and field operation without depending on Internet access.

Some parts are carefully engineered. Some parts are carefully attached with plastic cable ties. Both approaches have survived surprisingly well so far.
