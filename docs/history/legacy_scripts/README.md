# Legacy research scripts (archived 2026-10-15, BL-042)

One-off bench and analysis scripts from August-September 2026 (mount slew measurements, antenna coupling, RF chain
isolation, SDR config validation). Kept for the record, **not operational**: they predate the single frequency
source (sdr_tuning), the mount lock and the current capture path. To rerun one, copy it back to the repository root
(they import project modules from there) and review it first.

`../backups/`: `align_ultima_revision.tar.gz` and `calib_ultima_revision.tar.gz` - the 2026-09-28 ALIGN and CALIBRATE
wizard results and job records (data/ is not in Git).
